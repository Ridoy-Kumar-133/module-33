# My Next.js Project

This is a simple Next.js project where I practiced different Next.js and React concepts.

## 🚀 Technologies Used

- Next.js
- React
- JavaScript
- Tailwind CSS
- DaisyUI

## 📚 What I Practiced

In this project, I practiced:

- Next.js App Router
- Dynamic Routing
- Nested Routes
- Layout
- Navigation
- `usePathname`
- Dynamic Route Params
- `map()` and `find()`
- Reusable Components
- Next.js `Image`
- Server Components
- Fetching API Data
- Custom `not-found` Page
- Metadata
- Tailwind CSS
- DaisyUI
- Dashboard Layout
- Sidebar and Drawer
